# File Organizer

## Description
A simple command-line file organizer built with Python.

## Features
- Organize files automatically
- Separate image files
- Separate video files
- Separate document files
- Separate music files
- Separate archive files
- Automatically create category folders
- Check if the selected folder exists

## How to Run
```bash
python main.py
```
